# Pages Module

This directory contains page-level modules for the CampusMind prototype.

## Structure
- `home/` - Landing page
- `services/` - Service catalog
- `resources/` - Self-help library
- `counselor/` - Counselor profile
- `student-dashboard/` - Student overview
- `student-booking/` - Booking flow
- `student-appointments/` - Appointment management
- `counselor-schedule/` - Weekly schedule
- `counselor-note/` - Counseling notes
- `admin-dashboard/` - Admin overview
- `admin-services/` - Service management
- `login/` - Auth page
- `404/` - Not found page
- `403/` - Forbidden page
- `design-system/` - Design token reference

## Purpose
Each folder should contain the page HTML and any page-specific CSS/JS needed for isolated maintenance.
