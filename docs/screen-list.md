# Screen List

## 1. Màn hình công cộng
- Home / Trang chủ
- Services / Dịch vụ
- Resources / Tài nguyên self-help
- Counselor / Hồ sơ chuyên viên

## 2. Màn hình sinh viên
- Student Dashboard / Bảng điều khiển sinh viên
- Student Booking / Luồng đặt lịch 4 bước
- Student Appointments / Quản lý lịch hẹn

## 3. Màn hình chuyên viên
- Counselor Schedule / Lịch tuần chuyên viên
- Counselor Note / Ghi chú buổi tư vấn

## 4. Màn hình quản trị
- Admin Dashboard / Bảng điều phối hệ thống
- Admin Services / CRUD dịch vụ và người dùng

## 5. Màn hình hệ thống và lỗi
- Login / Đăng nhập
- 404 Not Found
- 403 Forbidden
- Design System / Design tokens

## 6. Màn hình phụ trợ
- Slide deck showcase
- Modal AI quiz
- Resource reader modal
- Appointment detail drawer
- Toast notification

## 7. Mục tiêu thiết kế
- Dễ hiểu trên máy tính và mobile
- Tối ưu trải nghiệm theo vai trò
- Tạo sự nhất quán về màu sắc, typography, spacing
