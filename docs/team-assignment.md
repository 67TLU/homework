# Team Assignment

## 1. Thành viên chính
- Nhóm trưởng: điều phối tiến độ và tích hợp tổng thể
- Front-end developer: xây dựng giao diện, layout, responsive
- Content/UX writer: viết copy, mô tả dịch vụ và tài nguyên
- QA/Reviewer: kiểm tra trải nghiệm và logic điều hướng

## 2. Phân công công việc
### Nhóm trưởng
- Quản lý timeline
- Theo dõi tiến độ
- Tổng hợp tài liệu
- Kiểm tra tính nhất quán dự án

### Front-end
- Thiết kế UI/UX
- Xây dựng màn hình
- Tích hợp style system
- Cập nhật layout và responsive

### Content/UX
- Viết nội dung mô tả dịch vụ
- Xây dựng nội dung cho tài nguyên tự giúp đỡ
- Cập nhật thông điệp cho người dùng

### QA/Reviewer
- Kiểm tra lỗi giao diện
- Test chức năng đặt lịch
- Kiểm tra màn hình mobile/tablet
- Báo cáo các điểm cần chỉnh sửa

## 3. Quy trình làm việc
- Phân tích yêu cầu
- Thiết kế cấu trúc màn hình
- Phát triển UI
- Kiểm tra và chỉnh sửa
- Nộp tài liệu và demo

## 4. Kết luận
Mỗi thành viên cần hiểu rõ vai trò, trách nhiệm và mục tiêu cuối cùng của dự án để đảm bảo hệ thống hoàn chỉnh và dễ bảo trì.
