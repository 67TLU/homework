# Team Assignment

## Thành viên
- Leader / Product owner: Quản lý mục tiêu, tối ưu trải nghiệm
- Frontend engineer: Xây dựng giao diện, responsive, component
- Content / UX: Viết copy, cấu hình thông tin dịch vụ
- QA / Reviewer: Kiểm tra UX, lỗi, consistency

## Phân công
- Trang chủ, service discovery: Frontend
- Student flows: Frontend
- Counselor flows: Frontend
- Admin flows: Frontend
- Docs & proposal: Team
